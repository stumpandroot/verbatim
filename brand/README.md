# Verbatim brand marks

Approved by Tim on October 18, 2026 (canvas: "Verbatim mark exploration", round 2).

| File | Use |
|---|---|
| `verbatim-mark-bars.svg` | App icon mark (B1). Persimmon icon with paper mark; ink and reversed variants. |
| `verbatim-colophon-rings.svg` | Colophon (R3a): website, onboarding, About, print. Not the app icon. |
| `verbatim-icon-persimmon-1024.svg` | Flat preview of the app icon at 1024 px. |

Colors: persimmon `#FA6B47`, paper `#F5F0E6`, ink `#26352E`. One color per mark; pink and sage stay in the interface.

Icon Composer: background color persimmon, one foreground layer from `verbatim-mark-bars.svg` in paper.
Turn glass off for the mark, and check Clear and Tinted modes at the smallest sizes on a device.
